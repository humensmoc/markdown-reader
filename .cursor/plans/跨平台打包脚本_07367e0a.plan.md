# 跨平台打包脚本（GenData 风格）

## 目标流程

```mermaid
flowchart LR
  drag[拖脚本到终端回车] --> cd[切到仓库根目录]
  cd --> compile[npm run compile]
  compile --> pkg[npm run package]
  pkg --> vsix[生成 name-version.vsix]
  vsix --> install[cursor --install-extension --force]
  install --> done[提示重载 Cursor 窗口]
```

当前文档中的手工步骤（见 [README.md](README.md) 与 [docs/how-to-release&update-local&extension-market.md](docs/how-to-release&update-local&extension-market.md)）：

```bash
npm run compile
npx vsce package --allow-missing-repository --no-rewrite-relative-links
cursor --install-extension ./<name>-<version>.vsix --force
```

脚本将上述三步合并为一键执行。

## 1. 统一 npm 脚本（单一真相来源）

修改 [package.json](package.json) 的 `scripts`：

| 脚本 | 作用 |
|------|------|
| `package` | 改为带 flag：`vsce package --allow-missing-repository --no-rewrite-relative-links` |
| `package:local`（新增） | `npm run compile && npm run package` |

`.bat` / `.sh` 只调用 `npm run package:local`，避免重复维护 vsce 参数。

**VSIX 文件名**：由 `package.json` 的 `name` + `version` 决定，当前为 `markdown-reader-0.0.2.vsix`（文档里旧的 `meow-report-markdown-viewer-*` 名称已过时，脚本用 Node 动态读取，不硬编码）。

## 2. 新增 `Package.bat`（Windows）

放在仓库根目录 [Package.bat](Package.bat)，核心模式与 GenData 一致：

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"
```

执行逻辑：

1. **环境检查**：`where node`、`where npm` 失败则打印提示并 `pause` 退出
2. **依赖检查（可选但推荐）**：若 `node_modules` 不存在，自动 `npm install`
3. **`npm run package:local`**：编译 + 打包
4. **解析 VSIX 路径**：`node -p "require('./package.json').name + '-' + require('./package.json').version + '.vsix'"`
5. **定位 Cursor CLI**（按优先级）：
   - PATH 中的 `cursor`
   - `%LOCALAPPDATA%\Programs\cursor\resources\app\bin\cursor.cmd`（Windows 常见安装路径）
6. **`"%CURSOR%" --install-extension "%VSIX%" --force`**
7. 成功/失败均 `pause`，方便拖进 cmd/PowerShell 后看到输出（GenData 同款体验）

## 3. 新增 `Package.sh`（macOS / Linux）

放在仓库根目录 [Package.sh](Package.sh)：

```bash
#!/usr/bin/env bash
set -euo pipefail
cd "$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
```

执行逻辑与 `.bat` 对称：

1. 检查 `node` / `npm`
2. 无 `node_modules` 时 `npm install`
3. `npm run package:local`
4. Node 动态解析 VSIX 文件名
5. **定位 Cursor CLI**：
   - PATH 中的 `cursor`
   - macOS 回退：`/Applications/Cursor.app/Contents/Resources/app/bin/cursor`
6. `"$CURSOR" --install-extension "./$VSIX" --force`
7. 打印「请在 Cursor 中执行 Developer: Reload Window」

首次在 Mac 上需 `chmod +x Package.sh`（或在终端用 `bash Package.sh` 运行）。

## 4. 脚本设计要点

- **`%~dp0` / `BASH_SOURCE`**：无论从哪个目录拖入终端，都先切到仓库根目录
- **不修改 git 配置、不自动 publish**：仅本地 compile → package → install
- **Cursor 找不到时**：明确报错并列出 Windows / Mac 常见路径，提示用户在 Cursor 中执行「Shell Command: Install 'cursor' command in PATH」
- **不生成 meta 文件**：仅新增两个脚本，不改 `.vscodeignore` 等

## 5. 使用方式（实现后）

| 平台 | 操作 |
|------|------|
| Windows | 把 `Package.bat` 拖进 cmd / PowerShell，回车 |
| macOS | 把 `Package.sh` 拖进 Terminal，回车（或 `bash Package.sh`） |
