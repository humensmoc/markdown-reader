# CodeMirror 6 实时预览编辑

0.0.9 用一个 `EditorView` 保存完整 Markdown 原文。格式显隐、属性卡片、公式、Mermaid 和网格表格都是源码的显示装饰；不再从正文 DOM 序列化 Markdown。旧 textarea、逐块 contenteditable 和 `saveContent` 写入入口已移除。

## 使用

打开 Markdown Reader 后直接输入。光标或选区进入格式节点时显示 Markdown 标记，内容继续保留样式；离开后恢复排版。设置和命令面板中的“显示全部 Markdown 标记”只切换装饰。普通链接用 Ctrl/Cmd+单击打开；引用数字单击跳转，随后可返回原文。

表格单元格点击后嵌入一个没有独立撤销历史的 CM6 视图，其事务转为主文档的精确范围修改。Tab/Shift+Tab 切换单元格，Enter 进入下一行同列，最后一行退出，Esc 返回正文。换行粘贴在单元格内表示为 `<br>`。分隔行、对齐符和未修改单元格的空格保持原样。转义竖线、行内代码和公式中的竖线不会被当成列边界。

正文与单元格输入立即同步到 VS Code `TextDocument`，不调用磁盘保存。Ctrl+S 和已有自动保存设置负责落盘；高亮和批注沿用显式保存。Ctrl+Z/Ctrl+Shift+Z/Ctrl+Y 交给 VS Code；Ctrl+B/Ctrl+I 对选文应用格式事务。块拖动也是一次源文本事务。

## 文档协议

`src/textChanges.ts` 定义源文本修改、UTF-16 行列坐标转换及非重叠修改映射。Webview 使用 LF，宿主按当前文档 EOL 写回，编码和 BOM 交给 VS Code 保持。

`src/liveDocument.ts` 为每个文档维护一条串行队列和近期版本快照，多个视图共享协调器。`webview/documentBridge.ts` 每次只发送一个未确认批次，后续输入暂存本地。初始化由 CM6 加载完毕后的 `ready` 发起。

| 消息 | 用途 |
| --- | --- |
| `documentInit` | 文档 URI、版本、原文和脏状态 |
| `applyEdits` | 客户端 ID、操作编号、基准版本、UTF-16 范围及预期旧文本 |
| `documentPatch` | 原文增量和来源操作编号；用于回执匹配及外部更新 |
| `editAck` / `editRejected` | 接受操作或保留本地输入并进入冲突状态 |
| `documentSaved` | 更新已保存状态 |
| `editorCommand` | 保存、撤销、重做 |
| `compareDraft` / `reloadLiveDocument` | 查看本地差异，或明确放弃未同步输入后重新加载 |

非重叠外部变化映射到本地待发送内容上；重叠变化暂停发送，保留屏幕上的本地草稿。冲突时先打开差异，把需要保留的草稿复制或另存，再重新加载。没有按时间忽略文档事件的窗口。保存失败保留未保存状态，允许重试。

## 前端组织

- `webview/editor.ts`：语法装饰、预览组件、表格、源选区映射、目录定位、折叠和块移动。
- `media/reportViewer.js`：复用原属性、目录、批注、引用浮层、样式配置和 Mermaid 放大界面，通过 `ReaderServices` 接收源码派生数据。
- `media/highlightFormat.js`：正文和表格共用的源码位置映射；原高亮、共享脚注评论和旧 JSON 高亮仍可读取。
- `media/readerMath.js`：原 KaTeX 渲染器及安全设置，预览不参与源文本序列化。
- `media/livePreview.css`：将已有字号、行宽、行距和主题变量应用到 CM6。

组合输入事务期间映射现有装饰，在 compositionend 后刷新；不启用 CM6 自带 history。Mermaid 异步完成后检查组件仍在文档中且源码匹配。CM6 虚拟化正文行，目录和批注使用源码位置，不需要隐藏的完整正文副本。

## 构建和验证

```sh
npm install
npm test
npm run verify-host
npm run package:local
```

`compile` 同时检查扩展和前端 TypeScript，esbuild 打包宿主和 Webview，并复制本地 Mermaid、KaTeX 及字体。VSIX 不依赖 CDN，不包含测试下载的 VS Code 或 node_modules。`verify-host` 使用 `.vscode-test/` 下的独立 VS Code，用户配置和扩展目录放在临时目录；不安装到用户日常环境。

自动检查覆盖：

- 原 frontmatter、批注状态和高亮持久化测试，包括 CRLF、共享脚注、旧数据转换和陈旧选区拒绝。
- 延迟回执、连续输入、多视图、Unicode/UTF-16、外部非重叠映射和重叠冲突。
- Playwright 键盘输入、标记显隐、拆段合段、单元格导航与撤销、跨格选文、高亮评论、引用返回、公式、Mermaid 放大、HTML 过滤、折叠和窄窗口。
- 1200 节长文的虚拟化、末尾定位与编辑。
- 真实 VS Code 自定义编辑器中的输入、脏状态、保存、原生撤销/重做、批量高亮原子性、外部文件更新及关闭重开。

中文文本输入已经过自动化检查；**中文输入法候选窗、选字及组合输入焦点仍需实际桌面验收**，不能由脚本插入中文或模拟 composition 事件代替。尚未逐个版本验证 Cursor 和最低支持版本 VS Code。

## 0.0.10 交互回归修复（2026-09-18）

- 彩虹标题恢复原六级配色：显示编号时只给编号着色，标题文字保持主题色；关闭编号时沿用原来的标题着色规则。
- 段落、标题、表格及复杂预览的拖动手柄放在左侧，不参与文本排版。标题拖动与折叠按钮分开；窄窗口保留固定操作边距，开关拖动功能不会挤压或移动正文。
- 引用跳转恢复来源的蓝色高亮框，返回时短暂高亮原文。装饰和返回位置随源码变更映射，高亮不增加行高。
- 修复鼠标点击落到下一行的两个原因：CM6 不计入块外边距，因此表格外边距造成后方坐标少算 24px；展开的单元格在捕获 mousedown 时收起，也会在点击定位前移动正文。块间距改为内部间距，预览容器包住子元素外边距，列表去掉外边距；单元格收起延后到点击事件处理完成。

新增 `scripts/verify-live-layout.js`，从真实 DOM 字符矩形获取鼠标坐标，再通过点击、键盘输入核对源码落点，避免用 CM6 自己的坐标反过来验证自己。覆盖表格、列表、公式、异步 Mermaid、HTML、定义列表、分隔线和属性卡片后方的正文，展开单元格后的点击，以及桌面/390px 窗口中的标题和嵌套格式。另检查六级编号颜色、手柄前后布局不变、折叠/拖动按钮互不遮挡、实际拖动、引用高亮与编辑后的返回定位。

`npm test` 与 VS Code 1.138.0 独立宿主回归通过。已查看编号颜色、手柄、引用框和窄窗口截图。交付包更新为 `markdown-reader-0.0.10.vsix`，不自动安装、提交或发布。
