# Cite 跳转定位测试文档

这个文档只用于测试 cite 跳转。每个测试点使用唯一的 source 编号，避免多个位置共用同一个 `[cite:n]` 造成误判。

测试方式：

1. 点击正文中的某个 cite 按钮。
2. 确认页面跳到文末对应编号的 Source 行。
3. 点击 Source 行右侧的“返回原文”。
4. 确认页面回到刚才点击的那个具体 cite 按钮，而不是同编号的其他位置。

## 1. 页面上方的单引用

测试点 A：这是文档靠前位置的唯一引用 [cite: 1]。点击后应该跳到 Source 1，返回后应该回到本段。

填充段落 A1：这里模拟报告中的背景说明。长文档阅读时，引用跳转通常用于核对数据、来源和论据。如果跳转目标不明确，用户会误以为没有跳到正确位置。

填充段落 A2：这个段落没有引用，只用于拉开距离。测试时请不要用目录跳转干扰 cite 行为，只点击正文中的 cite 按钮。

填充段落 A3：当从 Source 返回时，返回目标应该是刚刚点击的按钮本身。高亮只是辅助反馈，真正的正确性取决于滚动位置是否回到该按钮附近。

## 2. 页面中部的单引用

填充段落 B1：这一节在页面中部，用来观察从中部跳到文末再返回的表现。

填充段落 B2：长报告中，同一屏可能有多个段落、表格和标题。滚动逻辑应只依赖被点击按钮的 DOM id，而不是 source 编号反推正文位置。

测试点 B：这是文档中部位置的唯一引用 [cite: 2]。点击后应该跳到 Source 2，返回后应该回到本段。

填充段落 B3：这个段落没有引用。它用于确认返回时不会落到相邻段落，也不会落到上一节的引用。

填充段落 B4：如果返回后高亮正确但位置不对，说明滚动目标和高亮目标可能不是同一个元素，或者滚动被页面底部空间限制了。

## 3. 紧凑写法

填充段落 C1：这一节测试没有空格的 cite 写法。

测试点 C：紧凑写法应该也能识别 [cite:3]。点击后应该跳到 Source 3，返回后应该回到本段。

填充段落 C2：这里继续拉开距离，避免 Source 离正文太近导致肉眼难以判断跳转是否发生。

填充段落 C3：如果点击测试点 C 后停在 Source 2 或 Source 4，说明编号解析或 source id 生成有问题。

## 4. 段落内混合普通链接

填充段落 D1：这一节确认普通链接和 cite 链接不会互相影响。

测试点 D：普通链接 [Steam 示例](https://store.steampowered.com/app/570/) 和引用 [cite: 4] 在同一段。点击普通链接应打开外部浏览器；点击 cite 应跳到 Source 4。

填充段落 D2：返回原文时应回到 Source 4 对应的测试点 D，而不是普通链接附近或章节标题。

填充段落 D3：这个段落没有引用，继续用于拉开滚动距离。

## 5. 粗体中的引用

填充段落 E1：这一节确认格式化文本里的 cite 是否仍然可以定位。

**测试点 E：粗体文本里的唯一引用 [cite: 5]，点击后应该跳到 Source 5，返回后应该回到这行粗体文字。**

填充段落 E2：如果这个引用无法点击，说明内联 markdown 解析对粗体内容的递归处理有问题。

填充段落 E3：如果可以点击但返回位置不对，说明返回按钮保存的目标 id 不正确。

## 6. 表格中的引用

| 测试项 | 期望行为 |
| --- | --- |
| 表格引用 | 点击 [cite: 6] 后跳到 Source 6，返回后回到这个单元格 |
| 普通文本 | 这一行没有引用，只用于对比 |

填充段落 F1：表格中的引用按钮位于更复杂的 DOM 结构里，返回时应该仍然能定位到按钮本身。

填充段落 F2：如果返回时只回到表格附近但没有回到按钮所在行，需要检查 `scrollIntoView` 的目标是否是按钮元素。

## 7. 页面靠下的引用

填充段落 G1：这一节接近文末，用来测试靠下位置的返回行为。

填充段落 G2：靠下位置最容易受页面底部空间影响。如果底部 padding 不够，浏览器无法把目标滚到期望位置。

测试点 G：这是靠下位置的唯一引用 [cite: 7]。点击后应该跳到 Source 7，返回后应该回到本段。

填充段落 G3：继续添加正文，让 Source 区域和正文引用之间仍有明显距离。

填充段落 G4：如果这里返回不准，优先检查底部滚动余量和返回目标元素。

## 8. 最后一处正文引用

填充段落 H1：这是 Sources 之前的最后一个测试区。

测试点 H：这是 Sources 前的最后一个唯一引用 [cite: 8]。点击后应该跳到 Source 8，返回后应该回到本段。

填充段落 H2：这一段没有引用，作为正文和 Sources 之间的缓冲。

填充段落 H3：Sources 区域里的文本不应该再被解析成可点击 cite 按钮，否则会污染“返回原文”的目标。
