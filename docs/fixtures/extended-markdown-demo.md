# 扩展 Markdown 语法测试文档

这个文档用于测试引用块、删除线、任务列表、脚注、定义列表和 HTML 标签的渲染效果。每个章节对应一种语法，便于逐项核对。

测试方式：在插件阅读视图中打开本文件，对照下方「期望效果」检查渲染是否正确。

## 1. 引用块

测试点 A：单行引用块。

> 这是一段引用文字，应该显示左侧蓝色竖线与浅色背景。

期望效果：整段落在引用块样式内，与普通段落明显区分。

测试点 B：多行引用块。

> 引用可以跨多行书写。
> 第二行仍属于同一段引用。
>
> 空行引用行会开始新的引用段落。

期望效果：前两行合并为一个引用段落；空 `>` 行后另起一段引用。

测试点 C：引用块内的行内格式。

> 引用内支持 **粗体**、*斜体*、~~删除线~~ 和 [链接示例](https://example.com)。

## 4. 脚注

测试点 G：正文脚注引用。

Markdown 脚注语法参考 PHP Markdown Extra[^md-extra]，也可使用命名脚注[^note-name]。

[^md-extra]: PHP Markdown Extra 脚注说明 — https://michelf.ca/projects/php-markdown/extra/
[^note-name]: 命名脚注的正文可以包含 **粗体** 与 `行内代码`。

期望效果：正文出现上标数字链接；页面底部自动列出脚注，点击可跳转，↩ 可返回引用处。

## 6. HTML 标签

测试点 I：行内 HTML。

段落内可使用 <mark>高亮</mark>、<kbd>Ctrl</kbd>+<kbd>S</kbd> 和 H<sub>2</sub>O / x<sup>2</sup> 等标签。

测试点 J：块级 HTML。

<details><summary>点击展开详情</summary>这里是 <strong>HTML details</strong> 块，展开后应显示此内容。</details>

<hr>

测试点 K：安全过滤。

以下危险标签应被过滤，只显示内部文本或完全忽略：

<script>alert("xss")</script>
<iframe src="https://example.com"></iframe>

期望效果：不执行脚本，不嵌入 iframe；`<script>` 标签本身不应出现在页面上。
